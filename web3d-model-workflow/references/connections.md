# 三种 Blender 控制方式

先确认 Blender 是否安装、当前工程、未保存内容和本轮可用工具。连接验证只读取版本或场景，不修改作品。

## 方式一：MCP 连接

适用于读取并修改当前打开的场景。先从可用工具中查找 Blender 相关工具，按真实参数读取场景或版本。不能仅凭配置文件存在就声称已连接。

若尚未配置，可从 Blender Lab 官方方案（https://www.blender.org/lab/mcp-server/）或社区方案（https://github.com/ahujasid/blender-mcp）中选择符合当前版本和客户端的一个。安装前读取所选方案当前文档，服务端与 Blender 插件配套使用，端口与配置以实际说明为准；不要同时部署两个方案占用同一端口。缺少安装授权时不代替用户变更环境，但可以继续检查可用的脚本路径。

MCP 不可用并不等于 Blender 不可用。能够继续完成任务时切换到脚本控制，不反复要求重启或修改安全设置。

## 方式二：脚本控制

适用于规则建模、重复部件、组装和导出。查找真实 Blender 可执行文件；macOS 常见路径为 `/Applications/Blender.app/Contents/MacOS/Blender`，先确认存在。使用 Blender 自带 Python 执行 `bpy`，不要假设系统 Python 能导入它。

读取已经保存的工程并执行任务脚本的形式：

```sh
"<Blender 可执行文件>" --background "<已保存工程.blend>" --python-exit-code 1 --python "<任务脚本.py>"
```

路径需替换为实际绝对路径。脚本保存到任务副本，不与界面进程同时写同一个工程。新建场景可以使用独立输出，已有项目先读取工程。先做低成本检查，再执行耗时导出或渲染。记录退出状态、产物路径，并实际重开验证。

## 方式三：界面操作

适用于操作演示和只有界面入口的功能。使用宿主明确提供的电脑操作工具读取真实界面，再点击、输入和检查。不可假设按钮位置，也不可在界面工具不可用时用未授权方式模拟操作。

缺少界面权限时，说明这一条路径当前不可用，继续使用已可用的 MCP 或脚本路径完成允许的任务。不能把“界面不可控制”写成“Blender 无法使用”。

## 中断与保存

超时先查看场景、进程和输出文件，确认是否已经执行。不要立即重发建模或生成任务。修改前保留工程副本，生成后保存原始资产。连接成功只代表能读取或操作，不代表成品质量已验证。
